# 实验 #10 和 #11：访存重放与 MMU 边界

**采用方向 B。** i386 的两个派发入口共用同一个冷重放实现，保留各自的故障与续跑语义。i386 `off` 的 GNU 十项总耗时增加 0.97%，峰值 RSS 中位数从 148.4 降到 146.8 MiB。`region` 总耗时下降 1.46%，RSS 从 507.2 升到 508.3 MiB。整个双 Guest dylib 的 Release `__text` 只增加 244 B（0.004%）。

`region` 的 i386 GM-9 在 B 中下降 10.98%，在只修改 AArch64 的 A 回填对照中也下降 9.29%。B 的 i386 `region` 总耗时在六轮中各有三轮快于和慢于基线。该面板的波动限制了对收益的归因。B 在未修改的 AArch64 `off` 对照中也出现了 +2.01% 的总耗时变化。

**MMU 边界保留现有设计。** A 仅直连在 AArch64 `region` 中的总耗时下降 2.31%，GM-9 下降 0.34%，`off` 总耗时变化 −0.03%。代价是增加 183,816 B（2.93%）Release `__text`。在 A 仅直连基础上加回填，AArch64 `off` 的配对总耗时下降 1.97%，GM-9 下降 0.43%，`region` 总耗时增加 3.22%，GM-9 增加 2.94%。固定地址布局下，回填使约 1.34 万次探测由 L2 命中变为 L1 命中，`off` 的 L1 命中率提高约 0.003 个百分点，重放计数相同。回填额外增加 20,816 B Release `__text`。

## 实现

- **A 直连**。托管 AArch64 的分支慢路径和解码器直接调用 MMU，访存的标量处理器直调共享的 MMU 访存体。独立 C++ 解释器仍使用 `Memory` 回调。第一版把 MMU 访存体内联进烘焙处理器，Release `__text` 达 6,980,992 B，因此以下对照使用共享访存体。
- **A 回填**。在 A 直连基础上，记录重放最后一次成功的单页访问。指令可继续当前派发链时，从 MMU 重新校验并复制该页的 L2 标签和 addend。异常、重新取指、跨页访问、观测回调启用以及失效块均遵循原有的退出或清空行为。
- **B**。i386 的读请求和写请求共用一个 32 B 描述体，`MemoryOpRestart` 和 `MemoryOpRetry` 共用一个处理待决访存的冷函数。两个入口保留各自的延续位置，读和 RMW 可重进原指令，已提交副作用的写重放继续下一条指令。故障可挂起性、EIP 和标志位提交以及 JIT 的入口 ABI 都沿用现有语义。

## 测量

基线为 `b255c1c2`。主机为 Apple M5 Max，macOS 27.2.1，Homebrew Clang/LLVM 21。双 Guest Release ThinLTO 和 3m 烘焙预设启用 LLVM JIT，运行时用 `JitMode=off` 或 `region`，块缓存 400 MiB，动态特化及预链接缓存关闭。所有配置复用同一套托管 CLI 和各自架构的 GNU rootfs。构建持有共享锁，计时和校验持有同一文件的排他锁。

每套构建按两个 Guest 和两个 JIT 模式跑六轮。偶数轮反转执行顺序，每两轮轮换首个配置。每次启动运行 GNU 十项，使用 `run_workloads` 校验全部输出的 SHA-256。绝对时间为中位数，Δ 为同轮配对比值的中位数。GM-9 排除 `du`。CLI 时间包含启动及退出。RSS 为宿主峰值及六轮范围。Mach-O `__text` 是同一双 Guest dylib 的节大小。

统计版启用 `ENABLE_TLB_STATS=ON`，引擎退出时写出计数，合计 shell 及其子进程。L1、L2、Miss 的分母为统计到的读写探测总数。块内存是本次运行累计分配的解码块字节数。统计版额外插桩的耗时单独列出。 [逐轮数据与二进制 SHA-256](measurements.json) · [GNU 基准清单](../../manifests/baking-workloads.json)

## 验证

A 仅直连、A 回填和 B 都通过 24 项 CTest，覆盖独立 AArch64 解释器、托管 AArch64 MMU、两套 LLVM JIT 和 i386 待决访存。三个候选各通过 3,276 项 `Fiberish.X86.Tests`。当前主机的 Clang/libc++ 组合需要给 `specialization_index_test` 单独定义 `INFINITY`，基准库使用常规编译参数。

正式面板共 192 次 CLI 启动，每次验证十项 SHA-256。固定地址布局诊断另验证 320 项。两组合计通过 2,240 项输出校验。固定布局只用于诊断，统计计数通过临时原生插桩收集。
